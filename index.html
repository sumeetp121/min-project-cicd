Configure in minutes with simple YAML

Define your entire pipeline as code. Version it, review it, and keep it right beside your app.

  • ✓ Declarative, human-readable syntax
  • ✓ Reusable templates & shared workflows
  • ✓ Matrix builds across versions & platforms
  • ✓ Conditional stages and manual approvals
.flowci.yml 
# FlowCI pipeline configuration
name: deploy-production
on:
  push:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci
      - run: npm test
      - run: npm run build

  deploy:
    needs: build
    steps:
      - run: flowci deploy --prod 🚀
